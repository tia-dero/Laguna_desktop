LAGUNA 2.6
Scrivania in stile macOS per HP EliteBook 840 G5 e Windows 11

AVVIO
- Online: https://tia-dero.github.io/Laguna_desktop/
- Offline: scarica lo ZIP del repository, estrailo e apri index.html
  in Edge o Chrome. Puoi usare Avvia.cmd nella stessa cartella.
- Per un'icona su Windows, fai clic destro su Avvia.cmd e scegli
  Mostra altre opzioni > Invia a > Desktop (crea collegamento).
- Premi F11 o usa Schermo intero nella barra per occupare il display.
  Chiudi la scheda o la finestra del browser per tornare a Windows.

SCRIVANIE
- Università: apri Orario e appunti, scegli un giorno e annota le lezioni.
  Apri JARVIS University OS per vedere il sito in una finestra di Laguna.
  Se serve, usa Cambia indirizzo per impostare l'indirizzo HTTP o HTTPS.
  Se il sito non si vede nella finestra, usa Apri in una scheda.
- Foto: scegli la cartella della Nikon o più file dal PC. Laguna mostra
  miniature e anteprime per JPEG, PNG, WebP, AVIF, GIF e BMP. Per vedere
  un RAW Nikon NEF o NRW, apri una copia JPEG. I file sono in sola lettura.
  Riapri la cartella per riprendere dall'ultima foto selezionata.
- Progetti: tieni note di stampa 3D e di codice, apri l'anteprima locale
  dei file supportati o visita il repository che hai salvato. Per avviare
  Cura, Esplora file o VS Code usa le icone di Windows.

Passa tra le tre scrivanie dalla barra in alto. Mission Control gestisce
anche scrivanie aggiuntive e spostamento delle finestre. Ogni scrivania
ha il suo sfondo e ricorda le finestre quando usi lo stesso browser e
lo stesso indirizzo o percorso di apertura.
Trascina il titolo o la maniglia a puntini per spostare un riquadro.
Da tastiera seleziona la maniglia e usa le frecce, oppure premi Home per
ripristinare la posizione iniziale.

COMANDI
- Tieni premuto Alt e premi Q per scorrere tra le app aperte. Rilascia
  Alt per attivare quella scelta. Oppure usa Finestra > Cambia app.
- L'icona Download del Dock apre la pila dei file virtuali. Apri un file
  con un clic, oppure trascinalo in un'altra cartella del Finder.
- I menu seguono la finestra attiva, con azioni di Finder, JARVIS e Foto.
- Finestra > Affianca JARVIS e appunti apre entrambi in Università.
  Trascina una finestra verso un bordo per affiancarla, oppure fai clic
  destro sul pulsante verde. Un clic sul verde ripristina la misura.
- Finder: doppio clic per aprire, Spazio per l'anteprima, + per una scheda.
  Clic destro o Azioni Finder per gestire gli elementi virtuali.
- Tieni un file virtuale sopra una cartella del Finder per aprirla senza
  rilasciarlo. Ripeti sulle sottocartelle e lascia il file a destinazione.
  Lo spostamento riguarda solo i file virtuali di Laguna.
- In Impostazioni > Angoli attivi assegna a ciascun angolo Mission Control,
  Mostra scrivania o Blocca schermo. Gli angoli partono disattivati.
  Tieni il puntatore nell'angolo per circa mezzo secondo. Per rivedere
  le finestre, esci e rientra nell'angolo o usa Vista > Ripristina finestre.
- Spotlight: Ctrl + Spazio. Widget: menu di sistema > Modifica widget.
  Scegli fra otto widget, inclusi Note rapide, Timer, Orario, Progetti
  e Convertitore mm/cm/pollici. Trascina l'angolo in basso a destra
  per ridimensionare, oppure selezionalo con Tab e usa le frecce.
  Il clic destro offre i formati predefiniti. Le misure vengono salvate.
- Dock: clic per aprire, trascina le icone fissate per riordinarle.
  Per la scomparsa automatica usa Impostazioni > Dock.
- Sfondo: Impostazioni > Sfondo apre la galleria della scrivania attiva.
- Blocco simulato: menu di sistema > Blocca schermo. Premi Invio per uscire.
