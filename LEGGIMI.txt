LAGUNA 1.3
Simulatore desktop gratuito e offline per Windows 11

NEL BROWSER
Apri https://tia-dero.github.io/Laguna_desktop/

SU WINDOWS, ANCHE OFFLINE
1. Dalla pagina del repository scegli Code > Download ZIP.
2. In Esplora file, fai clic destro sullo ZIP e scegli Estrai tutto.
3. Apri la cartella estratta e fai doppio clic su index.html con Edge o
   Chrome. Puoi anche aprire Avvia.cmd per usare il browser predefinito.

COMANDI
- Dock: apri un'app o richiama una finestra minimizzata.
- Finestre: trascina la barra del titolo. Ridimensiona dal bordo destro,
  dal bordo inferiore o dall'angolo in basso a destra.
- Finder: fai doppio clic per aprire un elemento. Con la tastiera usa Tab
  e Invio. Clic destro o Azioni Finder apre il menu per creare, rinominare,
  spostare, importare ed esportare. Apri un documento di testo per scriverci.
- Anteprima rapida: seleziona un elemento e premi Spazio. Esc la chiude.
- Schede Finder: usa il + per aprire una scheda. Il menu Vista permette
  di ordinare gli elementi per nome o tipo.
- Trascinamento: usa Ctrl + clic per selezionare più elementi o Maiusc +
  clic per un intervallo. Trascinali su una cartella o sul Cestino.
- Cestino: seleziona un elemento e scegli Ripristina da Azioni Finder.
- Mission Control: clicca l'icona con due finestre nel Dock. Puoi creare
  scrivanie, poi trascinare le finestre sulle miniature o usare Sposta in.
- Centro di Controllo: clicca i cursori in alto a destra per cambiare
  tema, sfondo, animazioni e schermo intero.
- Impostazioni > Sfondo: scegli una delle tre interpretazioni Laguna
  ispirate ai Mac del 2026, o carica una foto con Scegli immagine.
  Scarica gli sfondi Apple apre i collegamenti agli originali disponibili.
- Spotlight: premi Ctrl + Spazio per cercare app e file virtuali.
- Schermo intero: premi F11 nel browser.

DISCO VIRTUALE E FILE DI WINDOWS
Da una cartella virtuale, Azioni Finder > Importa copia da Windows crea
una copia del file nel simulatore. Il limite per file importato è 256 KiB.
Esporta copia scarica il documento o il file importato.

Finder > File locali > Scegli file apre il selettore del browser per
visualizzare un file di Windows in sola lettura. Laguna mostra i primi
256 KiB dei file di testo e le immagini supportate fino a 12 MiB.

Disco virtuale, appunti, preferenze e disposizione delle finestre vengono
conservati dal browser quando la memoria locale è disponibile. Per
ritrovarli, usa lo stesso browser, profilo e indirizzo o percorso di
apertura. Esporta i file che vuoi conservare anche fuori dal browser.
