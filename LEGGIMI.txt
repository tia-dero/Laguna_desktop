LAGUNA 3.0.6
Scrivania in stile macOS per HP EliteBook 840 G5 e Windows 11

AVVIO
1. Estrai lo ZIP di Laguna 3.0.6 e metti i file in una cartella stabile.
2. Apri Laguna.html in Edge o Chrome. Il file funziona da solo, anche offline.
3. Per un'icona sul desktop di Windows, fai clic destro su Avvia.cmd,
   scegli Mostra altre opzioni > Invia a > Desktop (crea collegamento).
   Lascia Avvia.cmd accanto a Laguna.html.
4. Premi F11 o usa Schermo intero nella barra di Laguna. Chiudi la scheda
   o la finestra del browser per tornare a Windows.

UNIVERSITÀ, FOTO E PROGETTI
- Università. Apri Orario e appunti, scegli un giorno e scrivi le lezioni.
  Apri JARVIS University OS per vedere il sito in una finestra di Laguna.
  Se serve, usa Cambia indirizzo e inserisci un indirizzo HTTP o HTTPS.
  Se il browser o il sito impediscono la visualizzazione nella finestra,
  usa Apri in una scheda. Per localhost avvia prima il server JARVIS.
- Foto. Scegli una cartella o più file JPEG, PNG, WebP, AVIF, GIF o BMP.
  Usa le miniature o i pulsanti freccia. I RAW Nikon NEF e NRW appaiono
  nell'elenco. Per vederli in anteprima, apri una copia JPEG.
- Progetti. Registra filamento, impostazioni e prove di stampa o apri il
  selettore per vedere le informazioni di un file. Nella sezione Codice
  salva il tuo collegamento al repository e tieni traccia delle idee.

Apri le app dalla barra in alto con Applicazioni.
Fai clic su una zona vuota dello sfondo per vedere la scrivania.
Un altro clic ripristina le finestre.

Apri Laguna con lo stesso browser e dallo stesso percorso per recuperare
finestre, appunti e widget. Laguna parte dallo sfondo della scrivania
che era attiva e riunisce i testi delle Note rapide. Puoi cambiare
sfondo da Impostazioni. Le foto restano in sola lettura sul PC.
Quando riapri Laguna, scegli di nuovo la cartella: Laguna ricorda il
nome dell'ultima foto aperta.

APPLICAZIONI
Fai clic su Applicazioni nella barra in alto oppure usa Spotlight.
- Calendario: scegli una data, aggiungi un titolo e, se vuoi, un orario.
  Gli appuntamenti si salvano nello stesso browser.
- Orologio: imposta il timer da 1 a 120 minuti oppure usa il cronometro
  con i giri. Alla scadenza il timer mostra un avviso in Laguna.
- Musica: scegli più file audio dal PC per creare la coda di riproduzione.
  Laguna apre i file in sola lettura e li riproduce nel browser.
  La riproduzione continua quando chiudi la finestra. Esci dall'app
  per fermarla e svuotare la coda.
- Promemoria: aggiungi, spunta o rimuovi attività. Le modifiche compaiono
  anche nel widget Promemoria.
- Contatti: salva e cerca nomi, telefoni ed email nello stesso browser.
- TextEdit: scrivi o apri un file di testo. La bozza si salva nel browser.
  Usa Scarica copia per ottenere un file separato. L'originale resta intatto.

ALTRE FUNZIONI
Finder > File > Importa copia da Windows accetta file fino a 50 MB.
Laguna salva le copie nel browser. Se la memoria del browser non è
disponibile, Finder indica che la copia vale solo per la sessione.
L'anteprima del testo mostra al massimo 256 KiB. Usa Esporta copia
per scaricare il file completo.

Il pulsante verde porta la finestra a tutto schermo, sopra la barra
dei menu e dietro al Dock. Premi di nuovo il verde o Esc per uscire.
F11 attiva o disattiva lo schermo intero del browser.

Nel Finder, Ctrl+C copia i file e le cartelle virtuali selezionati.
Apri la cartella di destinazione e premi Ctrl+V. Ctrl+Z annulla
l'ultima operazione sui file virtuali durante la sessione.
Nelle app di testo, Ctrl+C, Ctrl+V e Ctrl+Z usano i comandi del browser.
Ctrl+F cerca per nome nella cartella del Finder, nel testo quando
stai scrivendo o in Spotlight negli altri casi.

Il pulsante giallo minimizza la finestra con l'Effetto Genio. Fai clic
sulla miniatura a destra nel Dock per ripristinarla nella sua scrivania
con le stesse dimensioni e posizione. Impostazioni > Animazioni >
Ridotte disattiva l'effetto.

Il puntino sotto un'icona indica una finestra aperta, anche minimizzata.
Il pulsante rosso chiude la finestra e il puntino scompare.
Fai clic sull'icona per riaprire una finestra. Per uscire dall'app
scegli Esci dal suo menu o con il clic destro nel Dock.

Tieni premuto Alt, premi Q per scorrere tra le app aperte e rilascia
Alt per attivare quella selezionata. Maiusc inverte la direzione.
Puoi anche usare Finestra > Cambia app. Se il cursore è dentro il sito
JARVIS, fai clic sulla barra di Laguna prima di usare la scorciatoia.
L'icona Download nel Dock apre la pila dei file virtuali. Puoi aprirli,
trascinarli nel Finder o trascinare un file virtuale sull'icona.

Nel Finder, tieni un file virtuale sopra una cartella per aprirla senza
rilasciare il file. Ripeti sulle sottocartelle e rilascia a destinazione.
Il trascinamento sposta solo gli elementi virtuali di Laguna.

In Impostazioni > Angoli attivi puoi assegnare Mostra scrivania o
Blocca schermo a ciascun angolo. Gli angoli partono disattivati.
Tieni il puntatore nell'angolo per circa mezzo secondo. Per rivedere le
finestre, esci e rientra nell'angolo o usa Vista > Ripristina finestre.

I menu File, Modifica e Vista seguono l'app attiva. Dal Finder scegli
File > Apri un file da Windows per aprire un PDF in Anteprima con il
lettore in sola lettura del browser. Usa il menu PDF per ingrandire
la finestra. Usa il menu File per scaricare una copia o aprire il
documento in una scheda. Finder mostra le azioni sui file,
JARVIS permette di cambiare indirizzo e ricaricare la pagina, Foto
mostra i comandi per aprire le immagini e sfogliarle.

Apri Finestra > Affianca JARVIS e appunti per usare entrambi sulla
scrivania. Per affiancare altre finestre, trascina il titolo
verso il bordo sinistro o destro e rilascia quando vedi l'anteprima.
Puoi anche fare clic destro sul pulsante verde per scegliere il lato.
Un clic sul verde ripristina la misura precedente.

Per aggiungere widget, scegli Modifica widget dal menu di sistema.
La galleria include Orologio, Calendario, Promemoria, Note rapide, Timer,
Orario, Progetti e Convertitore mm/cm/pollici. Trascina l'angolo in basso
a destra per ridimensionare liberamente, oppure selezionalo con Tab e
usa le frecce. Il clic destro offre i formati predefiniti. Le misure
vengono ricordate. Se i widget si sovrappongono, prova Disponi widget
dal menu di sistema.

Per il blocco simulato usa il menu di sistema e premi Invio per tornare
alla scrivania. Finder > File locali apre file di Windows in sola lettura.

Per avviare Cura, Esplora file o VS Code usa le icone di Windows. Laguna
apre i collegamenti web salvati nel browser. Le funzioni offline usano
solo il tuo computer. Un sito web come JARVIS richiede il suo server attivo.
